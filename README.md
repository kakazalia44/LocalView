# LocalView

LocalView — просмотр экранов компьютеров в локальной сети по запросу с Android.

## Windows
1. Скачайте артефакт **LocalView-Windows-EXE** из GitHub Actions.
2. Распакуйте архив в отдельную папку и запустите `start_agent.bat` (или `LocalView.exe`).
3. Разрешите доступ в брандмауэре Windows для частной сети.
4. В окне агента будут показаны IP-адрес, порт (по умолчанию 8765) и токен.

Агент запускается вручную, работает только пока открыто его окно и не регистрируется в автозагрузке, службах или планировщике задач.

## Android
Установите APK из артефакта **LocalView-Android-APK**. Добавьте каждый компьютер: название, его локальный IPv4-адрес, порт и токен. Нажмите «Получить экран» для запроса снимка.

Все устройства должны находиться в одной локальной сети или иметь маршрутизацию между подсетями. На роутере должна быть разрешена связь между Wi-Fi и Ethernet-клиентами.

## Безопасность и ограничения
- Доступ к снимку защищён токеном; используйте только доверенную локальную сеть.
- Передача идёт по HTTP внутри LAN, без TLS. Не пробрасывайте порт агента в интернет.
- Агент снимает весь виртуальный рабочий стол Windows (все подключённые мониторы).
- Это обычный захват изображения экрана; чтения памяти игры, внедрения DLL и управления игрой нет.
